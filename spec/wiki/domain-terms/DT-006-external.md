# External

**Definition.** A package or type that is used by the scanned code but not part of it, such as JDK or library types.

**In context.** Listed under *External* in the viewer. References that could not be resolved appear under *External › (unresolved)*.

**Distinguish from.** An [[DT-002-element]] of the scanned code.
