# Arc

**Definition.** The line the viewer draws between two visible rows for all dependencies between them and their contents.

**In context.** Downward arcs are green on the left, upward arcs blue on the right, upward arcs that close a cycle red. Thicker arcs stand for more references.

**Distinguish from.** [[DT-003-dependency]], the single reference in the code.
