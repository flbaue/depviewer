# depviewer is open source under the MIT license

**Constraint.** The code is published under the MIT license, copyright 2026 Florian Bauer.

**Rationale / origin.** depviewer is meant as a free alternative to commercial architecture tools ([[GOAL-001-architecture-as-code-checked-against-the-real-dependencies]]).

**Impact.** Every dependency must be compatible with MIT. Today there are none in the core.
